# NiceGUI Simple Demo

A simple, interactive UI built with Python and [NiceGUI](https://nicegui.io/).

## Features Included
- **Header & Dark Mode**: Top bar with title and instant dark/light theme toggling.
- **Reactive Greeting**: Real-time two-way data binding from text input to text display and toast notifications.
- **Interactive Counter**: Increment, decrement, and reset actions.
- **Slider & Progress Bar**: Synchronized slider and progress bar demonstration.

## How to Run

1. Open your terminal in this directory:
   ```powershell
   cd C:\Users\angel\nicegui_demo
   ```

2. Run the application:
   ```powershell
   python main.py
   ```

3. Open your browser at:
   [http://localhost:8080](http://localhost:8080)
